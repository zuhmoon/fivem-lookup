“None visible” does not mean unprotected. This filter only knows whether a server runs a resource whose name is recognisable as an anticheat. Vendors routinely tell operators to rename it so cheaters can't fingerprint it — in a 608-server scan, 61% showed no recognisable name at all. Many of those are certainly protected. Treat this as “nothing advertised”, never as “no anticheat”, and never as a list of servers worth attacking.
